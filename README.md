> 게임 이미지와 로고의 권리는 각 권리자에게 있습니다. 자세한 내용은 [제3자 자산 및 권리 고지](ASSET_NOTICE.md)를 확인하십시오.

Nintendo 3DS용 **Stella Glow 영어판 Undub**(`CTR-P-BS3E`)에 적용하는 한국어 LayeredFS 패치입니다.
영문판 Undub을 선택해서 패치한 이유는 영문판을 대상으로 하면 영어 음성과 일본어 음성 양쪽을 선택 가능하기 때문입니다.
일본어 음성을 원하면 Undub 버전을, 영어 음성을 원하시면 오리지날 버전을 구하십시오.

- 대상 Title ID: `0004000000173700`
- 최신 버전: **v32**
- 기준 원본 CIA SHA-256: `9388921B8209F8F2741916335A33EDF0D661BE8F1450CAF38314D7EF309437C9`
- 패치 파일: RomFS 1,471개
- 패치 데이터: 21,199,590 bytes
- 완성 CIA와 원본 게임 데이터 전체는 포함하지 않습니다.

## 추가·변경 사항

이 절은 원본 영어판 Undub과 비교해 이 패치가 무엇을 바꾸는지 `CHANGELOG.md`, 빌드·검증 보고서, 롤백 감사 보고서, 커밋 기록, 릴리스 노트, 매니페스트를 근거로 정리한 것입니다. 괄호 안은 근거(커밋 해시, 파일, 릴리스 태그)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 번역 범위

- **번역 기준**: 게임 안의 영어 문장을 한국어로 바꿨습니다. v31부터는 일본어 원문과 영어판을 함께 대조했고, v32에서는 일본어 원문과 화자 ID를 기준으로 인물별 존댓말·반말과 말투를 다시 검수했습니다 (`BUILD_VERIFICATION_v31.md`, `BUILD_VERIFICATION_v32.md`).
- **음성**: 음성 파일은 바꾸지 않았습니다. 영어판 Undub을 대상으로 하므로 게임 설정에서 영어 음성과 일본어 음성을 모두 고를 수 있습니다. 영어 음성만 원하면 Undub이 아닌 원래 영어판을 쓰라는 안내가 있습니다(이 경우 동작 확인 기록은 없습니다).
- **대사(이벤트)**: 이벤트·자유 대화 파일(`romfs/event/*.flw`) 1,376개를 한국어화했습니다. 본편 이벤트(`EV00`~`EV21`)와 자유 대화(`TALK`) 등이 들어 있습니다 (`metadata/patch_manifest_v32.json`).
- **시스템 문자열**: `romfs/param/`의 문자열 파일 17개를 한국어화했습니다. 아이템, 스킬, 어빌리티, 인물, 미션, 상점, 세계 지도, 조율(튠), 바(아르바이트), 마이룸, 유대 대화 등의 이름과 설명이 포함됩니다 (`param/*.str`).
- **이미지 UI**: `romfs/indicator/`의 UI 그림 72개를 한국어화했습니다. 타이틀, 메뉴(장비·아이템·라피스·옵션·소지금 등), 전투 상단·하단 화면(시작·승리·패배·상태이상·레벨업·데미지·턴 표시 등), 장 제목과 지역 이름 9개, 조율 화면, 상점, 바, 저장 화면, 대사창·시스템창(`AUTO`→`자동`), 선택지 창, 도움말 창이 들어 있습니다.
- **글꼴**: 한글을 넣은 글꼴 4개(`font_common`, `font_common2`, `_font_common`, `_font_common2`)를 바꿨습니다.
- **번역하지 못하고 남은 곳**: 시스템 메시지 `특수 조건 달성!` 한 줄은 실행 파일 쪽(`code.ips`)에 있어서, v31.1에서 `code.ips`를 뺀 뒤로 영어로 나옵니다 (`CHANGELOG.md` v31.1).

### 게임 데이터 변경 (번역 외)

- **스킬·상태이상 수치**: 사용자가 정한 스킬 위력, 상태이상 확률, 오브 관련 수치 조정을 넣었습니다. 이 때문에 `param/skill_param.bin`, `param/ablity_param.bin`이 원판과 다릅니다. 어떤 값을 얼마나 바꿨는지는 저장소에 적혀 있지 않습니다 (`f675273`, `CHANGELOG.md` v31).
- **설명 보강**: 아이템·스킬·오브 설명을 실제 게임 안 수치와 대조해 고쳤고, 상태이상·강화/약화·오브(사각·자객·은자·필중 등)의 실제 판정과 효과를 설명에 적었습니다. 영어 일반명사로 남아 있던 적 이름 24종을 한국어로 바꿨습니다 (v31).
- **용어 통일**: `Defender/디펜더`→`수호자`(별도 기술 `Guardian`은 `수호신`), `울프`→`늑대`, `MOVE DOWN`→`이동력 하락`, 사쿠야 호칭 `공주무녀`, `비앙카 무기점` 등으로 맞췄습니다 (v31, v31.1, v32).

### 편의 기능

원판에 없던 새 편의 기능은 없습니다.

### 화면·그래픽 개선

- **글꼴 가독성**: 한글 대사 글자 획의 불투명도를 영문 수준으로 올렸고, `같`, `떻`, `몇`처럼 흐리게 구워진 글자는 픽셀 단위로 보강했습니다. 글자 매핑·문자 폭·파일 크기는 그대로입니다 (v31, `BUILD_VERIFICATION_v31.md`).
- **자간**: HP/SP, 문장부호, 괄호, 영문 글자, 숫자, `+`, `×`의 간격을 바로잡았습니다. 작은 설명용 글꼴의 `H` 폭을 11→10, `S`를 10→9, `」`를 12→6으로 줄였습니다 (v29, v31, `metadata/ROLLBACK_AUDIT_20260728.md`).
- **도움말 창 확장**: 긴 아이템·오브 설명이 겹치지 않도록 도움말 표시 영역을 넓혔습니다 (`indicator/help_window/d_help_window.arc.cmp`, v31).
- **전투 라벨 색 구분**: 불·물·바람·땅 강화와 HP 재생 라벨을 원본 윤곽·그림자는 그대로 두고 속성별 색으로 나눴습니다 (v31).
- **강화/약화 표기**: 스킬·특성의 강화/약화 표기를 화살표 모양으로 되돌렸습니다 (v31).
- **전투 상태 이미지**: 전투 상태·강화/약화 이미지 35개를 한국어로 바꿨고, `바람+`·`땅+` 아이콘 옆에 남던 영문 `d`, `h` 획을 지웠습니다. 상태 아이콘의 적색·청색 십자와 흰 윤곽, 투명도는 원본대로 남겼습니다 (v30).
- **배치 재구성**: 승리·패배 조건과 `조율 시작` 이미지는 일본판의 4글자 배치를 기준으로 다시 만들었습니다 (v30).
- **선택지 중앙 정렬**: 선택지 글자 판을 20.5px 옮겨, 원판에서 왼쪽으로 치우쳐 있던 2지선다·3지선다 선택지를 가운데로 맞췄습니다 (v32, `indicator/popup_window/choise_window.arc.cmp`).
- **메뉴 버튼**: `설정` 버튼과 `소지금` 라벨은 원본의 둥근 모서리·사선 형상을 살리고 글자만 바꿨습니다 (v31, 롤백 감사).
- **줄바꿈**: 영어 문장의 전치사·접속사 위치를 따라 기계적으로 들어갔던 강제 줄바꿈을 정리하고, 일반 대사창 2줄 제한을 넘던 문장을 다시 배치했습니다. 튜토리얼, 어빌리티 습득, 지원 효과 강화, 전투 결과 설명도 2줄 시스템 창에 맞췄습니다 (v32).
- **축약 대사 복원**: 글꼴 개선 전에 폭을 맞추느라 줄였던 대사 919건을 뜻을 살린 문장으로 되돌렸습니다. 이벤트 31,821행을 다시 대조했고 대사창 넘침은 0건입니다 (v31).

### 버그 수정

- **유대 이벤트 멈춤**: 2장 첫 자유 시간에 리제트와 대화하면 로딩이 끝나지 않던 문제(이슈 #1)를 포함해, 캐릭터 첫 유대 이벤트 14종을 고정 슬롯형으로 되돌려 문자열 재배치로 생기던 멈춤을 막았습니다. 아치볼드 후속 유대 이벤트 `EV13_07_0700D`도 고쳤습니다 (v31.1, `c9e84e0`).
- **`code.ips` 실행 실패**: 일부 환경에서 게임이 아예 켜지지 않았습니다. IPS는 적용할 때 원본을 확인하지 않아서, 압축된 `.code`에 적용되면 지정 위치(0x1C65E0)가 압축 데이터 한가운데를 덮어 실행 코드가 깨집니다. 그래서 v31.1부터 `code.ips`를 배포에서 뺐습니다 (v31.1).
- **회상 요약문 정렬**: 회상 이벤트 12개의 요약문 51개에서 고정 슬롯 여백이 화면 정렬에 들어가던 문제를 고쳤습니다 (v31.1).
- **빠진 대사**: 기존 추출기가 놓친 `FF` 접두 인라인 대사 22곳(21개 파일)과 이벤트 10곳에 남은 영문 `I...`를 한국어로 바꿨습니다 (v31.1, `docs/inline_event_strings_20260805.json`).
- **오역**: 폐도 파렌하이트의 `힐...다...! 크르릉!`처럼 영문 무대지시를 의성어로 잘못 옮긴 대사와 장면 문맥 오역을 일본어 원문 기준으로 고쳤습니다. 아나스타시아, 단테·도로시·로돌프와 힐다, 유안·노노카·니키 등의 말투 불일치도 고쳤습니다 (v32).
- **UI 넘침**: 전투 시작·조율 시작, 상점·아르바이트·발판 UI의 크기·잘림·넘침을 고쳤습니다 (v32).
- **이전 판 수정이 되돌아간 문제**: 이벤트 대사 복원본 419개가 재빌드 때 사라졌던 문제와, HP·SP·`」` 뒤 간격이 옛 값으로 돌아간 문제를 고쳤습니다. `AUTO`→`자동` UI 2개와 소지금 라벨 형상이 배포 원본에서 빠질 뻔한 것도 바로잡았습니다. 검증 스크립트가 매니페스트에 없는 파일(`UNLISTED`)과 파일 수 불일치도 잡도록 강화했습니다 (`60f7ce7`, `metadata/ROLLBACK_AUDIT_20260728.md`).

### 설치·제거 방식

- **형식**: LayeredFS 차분입니다. 원본 RomFS 26,997개 중 바뀐 1,471개 파일만 `luma/titles/0004000000173700/romfs/`에 들어 있고, 완성 CIA나 원본 게임 전체는 없습니다 (`metadata/patch_manifest_v32.json`).
- **지원 판본**: Nintendo 3DS용 *Stella Glow* 영어판 Undub(`CTR-P-BS3E`, Title ID `0004000000173700`) 전용입니다. 기준 원본 CIA의 SHA-256이 README 위쪽에 있습니다. 다른 지역판이나 일본 정식판에는 쓰지 않습니다.
- **실행 환경**: 3DS 실기는 Luma3DS의 **Enable game patching**, 에뮬레이터는 Azahar의 모드 데이터 위치를 씁니다.
- **검증**: `verify_patch.ps1`이 매니페스트에 적힌 1,471개 파일의 크기·SHA-256, 빠진 파일, 매니페스트에 없는 파일, 전체 파일 수를 확인합니다. 매니페스트에는 파일마다 원본·패치 후 크기와 해시가 둘 다 적혀 있습니다.
- **제거**: 모드 폴더(`romfs`)를 지우면 원래대로 돌아갑니다. 원본 게임 파일은 건드리지 않습니다 (추정: LayeredFS 방식이라서).
- **판 올리기**: 이전 판과 섞지 말고 통째로 바꿉니다. v31 이전 판을 설치했다면 남아 있는 `code.ips`를 지웁니다.

### 알려진 문제

- 3DS 실기에서는 실행해 본 적이 없습니다. 실기에서 글꼴·대사창·결과창 표시, 선택지 중앙 정렬, 상점·아르바이트·발판의 좁은 UI는 아직 확인이 필요합니다 (`BUILD_VERIFICATION_v32.md`).
- v31에서 남긴 확인 항목(복원 대사의 문맥과 줄바꿈, 보강한 글자의 가독성, `설정`·`소지금` 경계, 조정 수치의 실제 전투 반영)은 장시간 플레이로 확인한 기록이 없습니다 (`BUILD_VERIFICATION_v31.md`).
- `특수 조건 달성!` 메시지는 영어로 나옵니다.
- UI 크기와 글꼴 렌더링은 실제 3DS와 에뮬레이터 배율에 따라 조금 다르게 보일 수 있습니다.
- 저장 데이터는 패치에 들어 있지 않고, LayeredFS 패치를 바꿔도 지워지지 않습니다.
- 이슈 #1은 v31.1에서 고쳤다고 적혀 있지만 아직 열려 있습니다.

## Luma3DS 설치

1. 게임과 홈 메뉴를 종료합니다.
2. 배포 ZIP의 `luma` 폴더를 SD 카드 루트에 병합합니다.
3. 다음 경로가 존재하는지 확인합니다.

```text
luma/titles/0004000000173700/romfs
```

4. Luma3DS 설정에서 **Enable game patching**을 켭니다.
5. Stella Glow를 실행합니다.

## Azahar 설치

1. Azahar의 게임 목록에서 Stella Glow를 우클릭합니다.
2. 모드 데이터 위치를 엽니다.
3. 기존 구버전 패치가 있다면 혼합하지 말고 교체합니다.
4. `luma/titles/0004000000173700/romfs`의 내용을 해당 타이틀의 모드 RomFS 위치에 복사합니다.
5. 게임을 실행합니다.

이전 버전에서 안내했던 `code.ips`는 배포에서 제외되었습니다.
구버전을 설치한 적이 있다면 모드 폴더에 남은 `code.ips`를 삭제하십시오.

완성된 CIA가 필요한 경우에는 사용자가 보유한 원본을 직접 추출하여 패치하거나,
제공된 LayeredFS 형식으로 실행하십시오.

## 무결성 확인

PowerShell에서 다음 명령을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\verify_patch.ps1
```

검증기는 `metadata/patch_manifest_v32.json`에 기록된 RomFS 1,471개의
크기 및 SHA-256을 확인합니다.

## 구성

```text
luma/titles/0004000000173700/romfs/   패치 파일
metadata/patch_manifest_v32.json      파일별 원본/패치 해시
verify_patch.ps1                      패치 무결성 검사
CHANGELOG.md                          변경 기록
```
